## How I work with a dataset

1. **Understand the columns first.** I want to know what each field means before I decide what to measure.
2. **Look for comparisons worth making.** Category against category, period against period, segment against segment.
3. **Check the numbers against the story.** If a chart tells a neat story, I go back and see whether the data really supports it.
4. **Present it plainly.** Not every chart has to impress. It has to be useful.
